## Ejercicios

Carpeta [`Ejercicios/`](Ejercicios/):

| Notebook | Relacionado con |
| --- | --- |
| `Ejercicios01_DiccionarioAClase_REV.ipynb` | Clases y objetos |

| `Ejercicios03_CarreraCoches_REV.ipynb` | Simulación con objetos |
| `Ejercicios04_HerenciaMRO_REV.ipynb` | Herencia múltiple y MRO (casos de sucesión intestada y adopción) |
| `Ejercicios05_ProyectosPOO_REV.ipynb` | Laboratorio: [poo_animales](https://github.com/gracobjo/poo_animales) + [poo_inmobiliaria](https://github.com/gracobjo/poo_inmobiliaria) |

El ejercicio 04 aplica el MRO a un dominio real (sucesión *ab intestato* y adopción de mayor de edad). Es un **modelo didáctico**, no asesoramiento jurídico.

El ejercicio 05 resume los pilares POO con mini-modelos de animales (ABC, polimorfismo) e inmobiliaria (properties, AITP, regla del 35 %). Para el código completo, clona los repos enlazados.

## Cómo estudiar

1. Abre el notebook de teoría.
2. Practica en el ejercicio correspondiente de `Ejercicios/`.
3. Para MRO, empieza por la teoría (`11_…`) y continúa con `Ejercicios04_HerenciaMRO_REV.ipynb`.
4. Para integrar todo el Tema 2, haz `Ejercicios05_ProyectosPOO_REV.ipynb` y luego los repos completos.
